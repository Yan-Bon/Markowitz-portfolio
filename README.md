# Markowitz-portfolio
Markowitz Portfolio Optimization

## Overview

This project implements the classical Markowitz mean-variance portfolio optimization framework using Python.

The analysis was performed on a portfolio consisting of five companies:
- T-techologies
- Lukoil
- Polus
- RossetiMR
- Sber
Using historical price data, monthly asset returns were calculated and annualized to estimate expected portfolio returns and risk.

## Features
- Historical stock return analysis
- Covariance matrix estimation
- Efficient frontier construction
- Global minimum variance portfolio
- Tangency portfolio optimization
- Sharpe ratio maximization
- Portfolio risk and return annualization

## Technologies
- Python
- pandas
- NumPy
- matplotlib

## Results
The efficient frontier was successfully constructed for the selected assets.
The tangency portfolio achieved a maximum Sharpe ratio of approximately 0.94, indicating a relatively efficient balance between expected return and portfolio volatility.

The project demonstrates the practical application of modern portfolio theory, statistical analysis, and matrix-based optimization methods in finance.
